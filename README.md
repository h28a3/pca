# PCA
## はじめに
授業で学んだPCAについて理解度を高めるために，Pythonのライブラリを使用せず，PCAを行うコードを自作してみました．

## PCAとは
d次元のデータがn個あるとする．
このデータを並べた$`d×n`$行列をX，その各行の平均を求めた$`d`$次元ベクトルを$`\mu`$，共分散行列を$`\Sigma`$とする．
また$`\Sigma`$の固有値を大きい順に$`\lambda_1,\lambda_2,\ldots,\lambda_d`$とし，これを並べた$`d`$次元ベクトルを$`\lambda`$，各固有値に対応する固有ベクトルを順に並べた$`d×d`$行列をSとする．
$`\Sigma`$は実対称行列であることから，固有値は実数，固有ベクトルは正規直交系をなす．
よって$`S^T=S^{-1}`$となる．
また，$`\sqrt{\lambda_1},\sqrt{\lambda_2},\ldots,\sqrt{\lambda_d}`$を順に対角成分に並べた対角行列を$`\Delta^{\frac{1}{2}}`$とし，その逆行列を$`\Delta^{-\frac{1}{2}}=(\Delta^{\frac{1}{2}})^{-1}`$と表す．
このとき
$$Y=\Delta^{-\frac{1}{2}}S^T(X-\mu)$$
としてデータを変換すると，データの各要素の相関が0になる．
さらに，それぞれの要素の平均は0，分散は1となっている．

## PCAを行うメリット
例えばデータのクラスタリングを行う際，データの次元が大きすぎて処理に時間がかかってしまうことが多々ある．
そこでPCAを行うことによって，低次元化を行った上でクラスタリングを行うことができる．
